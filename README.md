# TravShell
TravShell is a web application designed to help users explore places and create their own travel plans. 
It integrates interactive maps and location search to make discovering destinations easier.

# Features
* <b>Place Search:</b> Search for places using Google Maps/Places APIs.

* <b>Interactive Maps:</b> Drag and drop your desired location and see how map updates with new pins.

* <b>Travel planning:</b> Create presonalized travel plans around places of interest.
* <b>Share your travel:</b> Make your travel public to other users, and let them use it for their own journey.

# Technologies
* <b>Backend and application:</b> C#, .NET 8, Blazor
* <b>UI component:</b> MudBlazor
* <b>Database:</b> Microsoft SQL Server/ Azure SQL Database
* <b>Maps and locations:</b> Google Maps Platform
* <b>Cloud hosting:</b> Microsoft Azure

# Project Structure
The solution is organized into seperate projects to help keep application logic,
core functionality, and infrustructure concerns separated.

# Deployment
The application has been deployed on Microsoft Azure

# Purpose 
This project was developed due to lack of such webapps where user can quickly create a trip plan and have it in a small and concise size.
Additionally project was developed to gain practical experience in web application development, database integration, external API integration and cloud deployment.
